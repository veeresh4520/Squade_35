## Scenario
A learner prints the first five multiples of a chosen number. The current sample values are already present in the Java file. Make the program produce the result required below.

## Task
At a stationery shop, the program is used for a short beginner exercise. Make it follow the stated rule for the supplied values. Keep the solution within basic Java syntax, variables, conditions, loops, arrays, strings, and simple methods.

## Expected output
```text
4 x 1 = 4
4 x 2 = 8
4 x 3 = 12
4 x 4 = 16
4 x 5 = 20
```
